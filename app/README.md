# Document Album A4 Print

Document Album A4 Print is an advanced Android application built with **Jetpack Compose** and **Kotlin** that enables users to scan, auto-detect edges, crop, and align multiple ID cards (Aadhaar, PAN, Voter ID, Driving License, Student ID, etc.) onto a single professional **A4 PDF page** ready for printing or sharing.

## Features
- **Smart Edge Detection & Cropping:** Automatically detects document borders and allows manual adjustment.
- **Multi-ID Layouts:** Arrange Front & Back ID cards, dual cards, or custom grids onto A4 layout sheets.
- **Local Storage (Room Database):** Secure, offline-first local persistence of documents and history.
- **PDF & Image Export:** Generate high-resolution A4 PDFs with custom passwords, grayscale filters, and brightness adjustments.
- **Material 3 Design:** Beautiful, responsive UI built with Jetpack Compose.
